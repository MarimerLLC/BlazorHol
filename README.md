## Summary

This is the Blazor HOL content for the VSLive! 6-Week Training & Certification Course "Blazor Developer Accelerator: Hands-On Skills for Real-World .NET Teams".

* [Requirements before attending](/docs/requirements.md)

Join this immersive 6-week VSLive! hands-on virtual course and learn to use Blazor. Based on the Razor markup syntax, it leverages HTML, CSS, and C# code so you can create compelling user experiences. Behind the markup is the modern cross-platform .NET framework, meaning that all your UI, business, and data access logic can be written in C#. Whether you are building web apps, modernizing WinForms/WPF, or shipping cross-platform apps with Blazor and .NET MAUI, this course shows you how to move faster with a single, unified .NET UI stack. Across six weeks of live instruction, weekly office hours, and hands-on labs you will build interactive applications using server, WebAssembly, and hybrid approaches, so that you can build apps with Blazor for web, desktop, and mobile.

Instruction sessions are held Wednesdays from 9:00 – 11:00am (central). Office hours are held Mondays from 9:00 – 10:00am (central).
