# Requirements

Before attending the course you must have one of the following:

* PC (💚 recommended)
  * Windows 10 or 11
  * Visual Studio 2026, Rider, or Visual Studio Code
* Mac
  * Rider or Visual Studio Code
  * ⚠️ The presenter does not have a Mac and can not help with Mac specific issues
* Linux workstation
  * Rider or Visual Studio Code
  * ⚠️ The presenter does not have Linux desktop and can not help with Linux specific issues

In all cases you must have:

* A developer-capable laptop or workstation
* .NET 10 SDK
* ASP.NET Core 10
* Git tooling
* A GitHub account
* A modern web browser
  * Edge, Chrome, Safari, or Firefox

Because this is a virtual course, you must also have:

* A reliable internet connection
* Speakers and a microphone
